# Hi, I'm Maélys 👋

**Fullstack Developer at Matis · Based in Paris, France**

I build applications from front to back — connecting thoughtful interfaces, backend logic, and data to create software that makes people’s lives easier.

Development is both my work and a passion that started long before my first job.

### From games to building software

My first introduction to computers was sitting on my dad’s lap, watching him play World of Warcraft and create his own plugins. Eventually, I stole his seat and started tinkering myself.

That curiosity led me to experimenting with games, running my own Minecraft servers, and eventually creating applications. I’ve always loved understanding how things work — then finding out what I could build or improve.

### What I do

At **Matis**, I work across the stack, from user interfaces and API design to business logic and databases.

I care about maintainable architecture, performance, and the details that make an application feel straightforward to use. I enjoy thinking through problems with others, sharing ideas, and turning complicated requirements into practical solutions.

Previously, I helped build **Frimity**, a startup connecting people with leisure activity providers. The platform brought together a **B2C mobile application** for organizing activities and a **B2B SaaS** for leisure businesses.
